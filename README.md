# Réplica do Tempo · dark-yt

Site do dark-yt, a ferramenta pessoal que produz e publica os vídeos do canal Réplica do Tempo.

- `index.html`: apresentação
- `painel.html`: métricas do canal em todas as redes, atualizadas a cada 30 minutos
- `privacy.html`, `terms.html`: política de privacidade e termos
- `callback.html`: retorno da autorização do TikTok

Os dados do painel são publicados pelo computador do dono num arquivo público. Não há chaves de acesso neste repositório.
